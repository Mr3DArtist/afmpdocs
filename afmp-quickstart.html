Blender add-on · Quick start

Auto Face Mocap Pro

Turn a video of a face into facial animation on your own character in Blender.

  • Blender 5.1 or 5.2 · Windows
  • 52 ARKit face shape keys
  • Internet once, to activate
Step 01

Install

01
  • Edit → Preferences → Add-ons → top-right ⌄ → Install from Disk… and pick the ZIP — don't unzip it first.
  • Tick Animation: Auto Face Mocap Pro.
  • Open it: in the 3D Viewport press N, then click the AFMP tab.

First use prepares the engine by itself — a few minutes, one time — then it says “Ready for Activation”.

Step 02

Activate — once

02
  • Preferences → Auto Face Mocap Pro → Accept Engine License (required).
  • Type a Seat Name, paste your Order # from the purchase email, press Activate License.

One Order ID works on one machine. Moving computers? Press Release Seat on the old one first.

Step 03

Your first mocap

03
  1. Video Sources → Import Videos — pick your take. (You can also record live from a phone or webcam.)
  2. 2. CHARACTER — select your character mesh in the viewport, press + to add it to the list, set the Character Type (Human / Stylized / Cartoon), then Register Character to save the preset.
  3. 4. ANIMATION — press Apply Mocap. The first press also analyzes the video, then bakes the animation onto the face shape keys.
Step 04

Tune it

04
  • Auto Face Mocap Tuning — analyzes the take and tunes it for this character.
  • Facial Expressions Intensity, Smooth Expressions, Lipsync Strength, Mouth Shift / Open / Width — the everyday fixes, all live while you drag.
  • Adjust Expressions — per-key control when one expression needs pinning down.
  • Side by Side View — your video running next to the animated character.
  • Adjust Mocap's Start Frame — slide the take along the timeline.

Not happy with a take? Remove it from the Mocaps list — the arrow beside the trash brings it back.

Step 05

If something goes wrong

05
Apply Mocap is greyed out
Add your mesh to the character list and press Register Character to save the preset.
It asks for a video
Import one first — step 03.
The face barely moves
Check the mesh has the 52 ARKit shape keys and the right Character Type.
“Activation failed”
Needs internet, a Seat Name, and the exact Order #.
“Activated on another machine”
Press Release Seat, or deactivate on the old machine.
Engine setup never finishes
Log: ~/.mr3d_mocap/logs/setup.log
